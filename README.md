# earbuds

всплывашка при подключении наушников honor earbuds x5 pro на android 16 под виво. косит под аирподсы на айос.

## че умеет

- плавающий поп-ап снизу экрана когда открываешь кейс
- темная и светлая тема системы сама подстраивается
- анимация наушников на один круг без бесконечного повтора
- векторная капсула батарейки с реальными процентами из блютуза
- свайп вниз или кнопка готово чтобы закрыть
- виброотклик как на айфоне
- не открывает по два поп-апа сразу
- не вылазит на заблокированном экране или когда дисплей выключен
- фоновый сервис висит в памяти и жрет 0% батареи без тупых таймеров

## как собрать

ставишь jdk 21, настраиваешь андроид сдк и пишешь в консоли:

```bash
./gradlew assemblerelease
```

готовый апк будет в `app/build/outputs/apk/release/app-release.apk`.
